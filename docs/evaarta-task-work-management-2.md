# e-Vaarta Task & Work Management 2.0

Implemented as a shared semantic work-management boundary across desktop, Android and iOS.

### Covered domain
Task lifecycle, assignment modes, assignment acceptance, dependency validation, capacity/workload, monitoring, stalled/overdue detection, evidence/decision/source links, and platform-native tests.

### Product direction
The remaining UI/runtime work should project this model into Kanban, List, Calendar, Timeline and Gantt rather than maintain separate task stores. Assignment intelligence should consider skills, project membership, capacity, availability and permissions; AI recommendations remain explainable and require policy authorization.

The full production gate still requires native builds, real calendar/identity integrations, offline lifecycle tests, performance tests, accessibility tests, adversarial inputs and human benchmark evidence.
